# M3E - Material 3 Expressive for Every Framework

> M3E v2.5.5 — Web Components implementing Material 3 Expressive design.
> All components use `m3e-` prefix. Import pattern: `import "@m3e/web/{component-name}";`
> Package includes a Custom Elements Manifest (`custom-elements.json`).
> Built with Lit. Requires import map for tslib, lit, lit-html, @lit/reactive-element, @m3e/web/core when used without a bundler.

## Components

### App Bar (`m3e-app-bar`)
Import: `@m3e/web/app-bar`
Top navigation bar for contextual info and actions.
- Slots: `leading`, `title`, `subtitle`, `trailing`
- Sizes: `small` (default), `medium`, `large` — set via `size` attribute
- `centered` attribute centers the title

### Autocomplete (`m3e-autocomplete`)
Import: `@m3e/web/autocomplete`
Enhances a text input with a suggestion panel.
- `for` attribute binds to an input element's id
- `m3e-option` children define available options
- `change` event fires on selection
- Properties: `selected`, `value`
- Filter modes via `filter` attribute: `contains` (default), `starts-with`, `ends-with`, `none`
- `case-sensitive` attribute for case-sensitive filtering

### Avatar (`m3e-avatar`)
Import: `@m3e/web/avatar`
Reusable identity primitive displaying visual/textual representation with consistent sizing, shape, and typography.
- Accepts textual initials, images, or icons via slots
- No default ARIA role (neutral, non-semantic)

### Badge (`m3e-badge`)
Import: `@m3e/web/badge`
Compact visual indicator for counts, presence, or emphasis. Attaches to icons, buttons, or other components.

### Bottom Sheet (`m3e-bottom-sheet`)
Import: `@m3e/web/bottom-sheet`
Sheet anchored to bottom of screen for secondary content.
- Open via `m3e-bottom-sheet-trigger` (nested in clickable element), `open` attribute, or `show()` method
- Close via `m3e-bottom-sheet-action`, remove `open`, or `hide()` method
- Lifecycle events: `opening` (cancelable), `opened`, `closing` (cancelable), `closed`
- Variants: **standard** (default, non-blocking) and **modal** (blocks interaction, scrim, focus trap, autofocus)
  - `modal` attribute enables modal mode
  - Modal: `cancel` event on scrim click, focus restored to trigger on close
- `handle` attribute shows drag handle; `handle-label` for accessible label (default "Drag handle")
- **Detents**: `detents` attribute defines snap positions
  - Named detents: `collapsed`, `fit`, `half`, `full`
  - Unit-based detents: percentages or pixels (e.g., `50%`, `300px`)
  - Mix named and unit-based in any order
  - `detent` attribute (zero-based index) sets initial detent; also settable on trigger via `detent` attribute
  - `--m3e-bottom-sheet-peek-height` CSS custom property controls content peek in collapsed state (default `0px`)
- `hideable` attribute allows dismissal by dragging past lowest detent
- `header` named slot for custom header content below drag handle
- ARIA: standard = `role="region"`, modal = `role="dialog"` + `aria-modal="true"`
- Trigger: `aria-controls`, `aria-expanded`; modal trigger: `aria-haspopup="dialog"`
- `secondary` attribute on trigger opts out of ARIA ownership

### Breadcrumb (`m3e-breadcrumb`, `m3e-breadcrumb-item`)
Import: `@m3e/web/breadcrumb`
Hierarchical navigation component.
- `m3e-breadcrumb-item` supports `href`, `target`, `rel` attributes
- `icon` slot on items
- Last item is automatically marked as current

### Button (`m3e-button`)
Import: `@m3e/web/button`
Semantic, expressive UI primitive for user actions.
- Variants: `elevated`, `filled`, `tonal`, `outlined`, `text` (default) — via `variant` attribute
- Shapes: `rounded` (default), `square` — via `shape` attribute
- Sizes: `extra-small`, `small` (default), `medium`, `large`, `extra-large` — via `size` attribute
- Slots: `icon` (before label), `trailing-icon` (after label)
- Toggle: `toggle` attribute for binary selection, `selected` for state; emits `input` (cancelable) + `change`
- `selected`/`selected-icon` slots for alternate label/icon when selected
- `disabled` / `disabled-interactive` attributes
- `type` attribute: `button` (default), `submit`, `reset`; `name`/`value` for forms
- Links: `href`, `target`, `rel`, `download` attributes → changes role to `link`
- ARIA: `role="button"`, `aria-pressed` for toggle, `aria-disabled="true"` when disabled

### Button Group (`m3e-button-group`)
Import: `@m3e/web/button-group`
Arranges multiple buttons into a unified layout.
- Variants: `standard` (default), `connected` — via `variant` attribute
- Sizes: `extra-small`, `small` (default), `medium`, `large`, `extra-large` — via `size` attribute (controls spacing)
- Selection: `multi` attribute for multi-select on toggle buttons
- ARIA: `role="group"`; single-select with toggles → `role="radiogroup"`, buttons → `role="radio"`
- Requires `aria-label` or `aria-labelledby`

### Calendar (`m3e-calendar`)
Import: `@m3e/web/calendar`
Month/year/multi-year views with date selection.
- Single-date and range selection
- Disabled rules: `min`, `max`, blackout
- `date` attribute for value; `change` event on selection
- ISO-8601 date parsing: `yyyy-MM-dd`, `yyyy-MM-ddTHH:mm:ss`, `yyyy-MM-ddTHH:mm:ssZ`, `yyyy-MM-ddTHH:mm:ss±HH:mm`

### Card (`m3e-card`)
Import: `@m3e/web/card`
Flexible container for presenting unified subject—text, media, actions.
- Slots: `header`, `content` (padded), `actions`, `footer`, `(default)` (no padding)
- `actions` slot supports `end` attribute on slotted element for right-alignment
- Variants: `filled` (default), `outlined`, `elevated` — via `variant` attribute
- `inline` attribute for inline rendering
- `orientation`: `vertical` (default), `horizontal` — via `orientation` attribute
- `actionable` attribute makes card an interactive surface
- `disabled` / `disabled-interactive` on actionable cards
- Links: `href`, `target`, `rel`, `download` on actionable cards → role becomes `link`
- ARIA: no role by default; actionable → `role="button"`; href → `role="link"`

### Checkbox (`m3e-checkbox`)
Import: `@m3e/web/checkbox`
Form-associated custom element (FACE) for boolean selection.
- Attributes: `checked`, `indeterminate`, `disabled`, `required`
- Events: `input` + `change`; `invalid` event
- `name`/`value` for form submission

### Chips (`m3e-chip`, `m3e-chip-set`, `m3e-assist-chip`, `m3e-filter-chip`, `m3e-filter-chip-set`, `m3e-input-chip-set`, `m3e-input-chip`, `m3e-suggestion-chip`)
Import: `@m3e/web/chips`
Expressive chip components for actions, input, filtering, and suggestions.
- **m3e-chip**: Non-interactive; nest in `m3e-chip-set` for spacing
  - Variants: `outlined` (default), `elevated` — via `variant` attribute
  - `m3e-chip-set` supports `vertical` attribute
  - Slots: `icon`, `trailing-icon`
- **m3e-assist-chip**: Smart/automated action chip
  - `icon` slot only (no trailing); `disabled`/`disabled-interactive`; `type`/`name`/`value`; `href`/`target`/`rel`/`download`
- **m3e-filter-chip** + **m3e-filter-chip-set**: Selectable filter chips
  - `icon` + `trailing-icon` slots; selected → icon replaced with check
  - `multi` attribute on set for multi-select; `selected` on chip for state
  - `input` (cancelable) + `change` events; `disabled`/`disabled-interactive`
  - `hide-selection-indicator` on set; FACE with `name`/`value`
- **m3e-input-chip-set** + **m3e-input-chip**: Input, display, manage discrete values
  - `input` slot for input element; `change` on input adds chip
  - BACKSPACE removes chips; DELETE removes focused chip
  - `change` event with `detail.type` ("add"/"remove"), `detail.value`, `detail.chip`
  - Prepopulate with `m3e-input-chip`; `removable` attribute
  - `disabled` on set disables everything; FACE with `name`
- **m3e-suggestion-chip**: Contextually relevant suggestions (equivalent to assist chip, different semantic intent)
  - `icon` slot only; `disabled`/`disabled-interactive`; `type`/`name`/`value`; `href`/`target`/`rel`/`download`
- ARIA: chip/chip-set = no role; assist/suggestion = `role="button"` (or `link` with href); filter single-select = `radiogroup`/`radio`, multi = `group`/`button`; input = `grid`/`row`/`gridcell`

### Content Pane (`m3e-content-pane`)
Import: `@m3e/web/content-pane`
Shaped surface with padding and vertical scrolling for document-like content.
- Inline padding auto-adjusted for scrollbar width compensation
- No ARIA role by default

### Datepicker (`m3e-datepicker`, `m3e-datepicker-toggle`)

### Dialog (`m3e-dialog`)
Import: `@m3e/web/dialog`
Presents important prompts, alerts, and actions.
- Slots: `(default)`, `header`, `actions`, `close-icon`
- Open via `m3e-dialog-trigger` (nested in clickable, `for` attribute) or `show()` method
- Close via `m3e-dialog-action` (sets `returnValue` from `return-value` attribute) or `hide()` method
- `closed` event on close; `cancel` event on backdrop click/Escape
- `dismissible` attribute shows close button; `close-label` for accessible label
- `disable-close` attribute prevents backdrop/Escape close
- `no-focus-trap` attribute disables focus trap
- `autofocus` attribute on action for initial focus
- `alert` attribute → `role="alertdialog"`
- Internal `dialog` element labelled by `header` slot

### FAB (`m3e-fab`)
Import: `@m3e/web/fab`

- Sizes: `small`, `medium` (default), `large` — via `size` attribute

- `disabled` / `disabled-interactive`

### FAB Menu (`m3e-fab-menu`)
Import: `@m3e/web/fab-menu`
Dynamic menu of related actions revealed from a FAB.

- `icon` slot on items for icon before label
- `disabled` on items; disabled FAB prevents menu opening
- Links: `href`, `target`, `rel`, `download` on items
- ARIA: `role="menu"` on menu, `role="menuitem"` on items; FAB gets `aria-controls`, `aria-haspopup="menu"`, `aria-expanded`

### Icon (`m3e-icon`)

- SVG icons via `@m3e/icons` package: `import "@m3e/icons/outlined/search";` or `import "@m3e/icons/outlined";`
- ARIA: `role="img"`; use `aria-hidden="true"` for decorative; otherwise label with `aria-label`/`aria-labelledby`

### Progress Indicator (`m3e-linear-progress-indicator`, `m3e-circular-progress-indicator`)
Import: `@m3e/web/progress-indicator`
Accessible, animated progress indicators.
- **Circular**: `m3e-circular-progress-indicator`
  - Variants: `flat` (default), `wavy` — via `variant` attribute
  - Determinate: `value` + `max` attributes; default slot for content
  - Indeterminate: `indeterminate` attribute (ignores `value`/`max`)
- **Linear**: `m3e-linear-progress-indicator`
  - Modes: `determinate` (default), `indeterminate`, `buffer`, `query` — via `mode` attribute
  - Variants: `flat` (default), `wavy` — via `variant` attribute
  - Determinate: `value` + `max`; wavy auto-transitions to flat at 100%
  - Buffer: `value` + `buffer-value`; wavy auto-transitions to flat at 100%
  - Query: pre-loading indication; ignores `value`/`max`
- ARIA: `role="progressbar"`, `aria-valuemin="0"`, `aria-valuenow`, `aria-valuemax`; always provide `aria-label`

### Search (`m3e-search-bar`, `m3e-search-view`)

Material 3 expressive search experience.

  - `contained` attribute for filled container when open
  - `query` event on input focus and value change (`detail.term`); `clear` event
  - `hide-search-icon` attribute
  - ARIA: overlay = `role="dialog"` + `aria-modal="true"`; provide `aria-live="polite"` for result updates

- `stretch` attribute; `header-position`: `before` (default), `after`
- `disabled` on tabs; `disable-pagination`

### Textarea Autosize (`m3e-textarea-autosize`)
Import: `@m3e/web/textarea-autosize`
Auto-adjusts textarea height to fit content.
- `for` attribute specifies textarea id
- `min-rows`/`max-rows` attributes
- `disabled` attribute
- ARIA: `role="none"` (presentational)

### Theme (`m3e-theme`)
Import: `@m3e/web/theme`
Non-visual element for dynamic color, motion, density, and focus indicators.
- `color` attribute: HEX color → derives full M3 color palettes as CSS custom properties (e.g., `--md-sys-color-primary`)
- `scheme` attribute: `light`, `dark`, `auto` (default, follows system preference)
- `contrast` attribute: `standard` (default), `medium`, `high`
- `density` attribute: `-3` (most compact) to `+1` (most spacious), default `0`; sets `--md-sys-density-scale` token
- `motion` attribute: `standard` (default), `expressive` — spring-based physics
- No ARIA role by default

### TOC (`m3e-toc`)
Import: `@m3e/web/toc`
Hierarchical table of contents for in-page navigation.
- `for` attribute: ID of container with headings to index
- Scans `h1`-`h6` and `m3e-heading`; reactive to DOM changes
- `m3e-toc-ignore` attribute on headings to exclude
- `overline` + `title` slots for heading (overline: 1 line, title: 2 lines, ellipsis truncation)
- `max-depth` attribute (default 2); depth relative to highest-level heading found
- ARIA: `role="navigation"`; items = `role="link"` + `tabindex="-1"`; active = `aria-current="true"`

### Toolbar (`m3e-toolbar`)
Import: `@m3e/web/toolbar`
Contextual actions, navigation, and controls.
- Variants: `standard` (default), `vibrant` — via `variant` attribute
- Shapes: `square` (default), `rounded` — via `shape` attribute
- `elevated` attribute for elevated surface
- `vertical` attribute for vertical orientation
- ARIA: `role="toolbar"`; vertical → `aria-orientation="vertical"`

### Tooltip (`m3e-tooltip`, `m3e-rich-tooltip`)
Import: `@m3e/web/tooltip`
Plain and rich tooltips.
- `for` attribute binds to target element
- `position`: `above`, `below` (default), `before`, `after` (BIDI-aware)
- `show-delay`/`hide-delay` attributes
- `disabled` attribute
- `touch-gestures`: `auto`, `on`, `off`
- **m3e-rich-tooltip**: `heading` slot for rich content

### Tree (`m3e-tree`, `m3e-tree-item`)
Import: `@m3e/web/tree`
Hierarchical data with nested expandable levels.
- `m3e-tree-item` children; `label` slot; `open` attribute for expansion
- `selected` attribute; `change` event; `selected` property
- `multi` attribute for multi-select
- `cascade` attribute with `multi` for cascade selection
- `icon`/`selected-icon` slots on items
- `toggle-icon`/`open-toggle-icon` slots for expand/collapse icons
- ARIA: `role="tree"` on tree, `role="treeitem"` on items; `aria-expanded` on expandable; single-select: `aria-selected`, multi-select: `aria-checked`; `tabindex="0"` + `aria-activedescendant` for roving focus; icons: `aria-hidden="true"`; disabled: `aria-disabled="true"`
