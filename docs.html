Authentication

Authenticate your API requests using the Authorization header with your API key.

Authorization: Bearer sk-your-api-key-here

Chat Completions

Generate text using any supported model across our aggregated provider network. We use the standard OpenAI format.

Endpoint

POST /api/chat/completions

Example Request

curl -X POST https://api.yourdomain.com/api/chat/completions \\
  -H "Content-Type: application/json" \\
  -H "Authorization: Bearer $API_KEY" \\
  -d '{
    "model": "gpt-4o",
    "messages": [
      {
        "role": "user",
        "content": "Explain quantum computing in simple terms."
      }
    ],
    "stream": true
  }'

Routing Preferences & Context

Our gateway automatically handles context limits based on your preferences. If you exceed a model's tier threshold (e.g. Heavy or Massive), the request may be compressed, blocked, or cost a multiplied amount of credits, depending on your configuration.
